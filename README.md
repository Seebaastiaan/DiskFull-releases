# DiskFull

Limpiador de disco para Mac (macOS 13 o posterior, Apple Silicon e Intel).

**[Descargar DiskFull.dmg](https://github.com/Seebaastiaan/DiskFull-releases/releases/latest/download/DiskFull.dmg)**

Este repositorio solo contiene las descargas. La primera vez que abras la app, macOS pedirá confirmarla en *Ajustes del Sistema → Privacidad y seguridad → Abrir igualmente*, porque aún no está notarizada por Apple.
